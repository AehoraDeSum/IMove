IMOVE / GUIDE / 1.1

Control the location from anywhere.

Manage the simulated location of an iPhone connected to your Mac over USB from the Mac app, the Android app, or a browser on iPhone/iPad.

What goes on which device?

The Mac only needs IMove.app. The USB tool is bundled inside it; no separate Python or virtual environment is required. Install the IMove APK on an Android phone. For remote access, install Tailscale on the Mac and on the Android/iPhone/iPad you will control it from. The iPhone connected over USB does not need Tailscale just to receive locations.

1. Prepare the Mac

  1. Unzip IMove-1.1.0-macOS-arm64.zip and move the single IMove.app into your Applications folder. Quit any older version first.
  2. Connect the iPhone over USB, accept the trust prompt and unlock the screen.
  3. In IMove → Connection → Real USB, scan for devices and choose the right iPhone. Press Mount developer image if needed. The first setup may need internet to download the image.
  4. Send a sample coordinate on the Location screen and check the result on the iPhone, or in Find My on the device of the person you share your location with.

IMove finds the USB tool automatically. Advanced tool selection is only there if you want to use a different tool.

2. Turn on remote access

  1. On the Mac, open IMove → Remote access → Start control page. Try on this Mac opens the local page.
  2. Install Tailscale on the Mac, sign in and grant the VPN permissions. Enable CLI integration in the Tailscale settings.
  3. In the Mac Terminal, test the connection with tailscale status, then run tailscale serve --bg 8765. The https://…ts.net address it prints is only reachable on your private network. Do not use Funnel.
  4. Install Tailscale on the controlling phone or iPad and join the same private network. Open the HTTPS address in that device's browser and sign in with the 32-character pairing code from the Mac app.

If the Mac App Store version of Tailscale has no command-line tool, use /Applications/Tailscale.app/Contents/MacOS/Tailscale serve --bg 8765. To turn remote access off, run tailscale serve off.

3. Use the Android app

  1. Install IMove-1.1.0-Android.apk over the existing app.
  2. Open the menu at the top left → Connection, enter the Mac's private HTTPS address and the pairing code, then tap Sign in.
  3. Use the menu to open Location, Map, Saved places, Routes or Tracking. The code is stored encrypted on the phone and removed with Sign out.

Locations, map and routes

Type a coordinate or tap the map to choose one. Saved places are shared between the Mac, Android and the web. Pick route points on the map in order; at least two points are required. Either split the total time evenly or give each pair of points its own minutes and seconds. On the B1 Marmaray, M2 and M6 lines you can pick boarding and alighting stations and add transfers. You can reshape each segment with waypoints on the map and calculate an Apple Maps walking route for the selected segment through the Mac. Walking calculations need internet: the Mac tries Apple Maps first, and if it gets no answer the coordinates are sent to the FOSSGIS Valhalla demo service. Line geometry is approximate third-party map data; timetables are not tracked live. Review the default durations before saving. The M2 Şişhane–Taksim path is shown approximately.

The USB refresh interval for locations and routes is 1–60 seconds. A new command does not start until the previous one finishes. On Android, 5-minute Tracking keeps running with the screen locked and shows a visible notification. Tracking on the web only continues while the page is open and visible.

Map and shortcuts

On the Location screen, tapping a saved place name fills in its coordinates; sending is a separate step. The Android map can open full screen and the web map can be enlarged. Both offer dark and light maps. Apple MapKit JS works in Android and web browsers but requires an Apple Developer Maps token, so this version uses OpenStreetMap data.

Launch at login

On IMove → Remote access you can choose to launch the app when you log in, find the selected USB target again and start the control page. After the Mac restarts, you need to be logged in, Tailscale must be connected, and the iPhone must be on USB and unlocked. After the first setup, confirm the connection by sending a USB command again.

IMove can show the last coordinate it sent, but that is not an independent measurement of what the other person actually sees in Find My. Check their screen if you need to be sure.
